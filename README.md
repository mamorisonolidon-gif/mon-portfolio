# Portfolio – Nirina Claudio RAHARISON

Portfolio statique (HTML, CSS, JavaScript), sans dépendance à installer.

## Structure
- `index.html` : contenu de la page
- `projet-budget.html`, `projet-pharma.html`, `projet-presence.html` : page de détail de chaque projet (bouton « Détails »)
- `style.css` : styles, thème clair/sombre
- `script.js` : bouton de thème
- `assets/` : placez ici votre photo et vos images
- `cv.pdf` : à ajouter à la racine (bouton « Voir mon CV »)

## À personnaliser
1. Remplacez les projets, l'expérience et l'e-mail dans `index.html`, puis le contenu de chaque page `projet-*.html` (contexte, objectifs, fonctionnalités, technologies, apprentissages, lien GitHub).
   Les images d'aperçu attendues sont `assets/budget.jpg`, `assets/pharma.jpg` et `assets/presence.jpg`.
2. Ajoutez votre photo dans `assets/` et remplacez le rond « NC ».

## Lancer en local
Ouvrez `index.html` dans le navigateur, ou lancez `python -m http.server`.

## Publier sur GitHub Pages
1. Poussez le dossier dans le dépôt `portfolio`.
2. Réglages > Pages > branche `main`, dossier `/ (root)`.
